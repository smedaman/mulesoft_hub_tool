Go to your repo, click Add file → Upload files, drag in your index.html, then click Commit changes.
# Or via Git CLI:
git clone https://github.com/smedaman/sreeni_mulesoft_hub
cd sreeni_mulesoft_hub
cp ~/Downloads/mulesoft_hub_v41.html index.html
git add index.html
git commit -m "Add Sreeni MuleSoft Hub"
git push
❸ Enable GitHub Pages
1. Go to your repo → Settings
2. Scroll to Pages in the left sidebar
3. Under Source, select Deploy from a branch
4. Choose main branch → / (root)
5. Click Save

After ~60 seconds your site goes live at:
